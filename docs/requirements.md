# Daily Wins 第一版需求文档

版本：1.0  
日期：2026-10-17  
状态：需求经多轮讨论确认，作为后续设计和开发依据。

## 1. 产品目标

为个人提供一个以月历为入口的小任务和成就记录工具。每天以完成三个小任务为目标，让日常努力可见，通过轻量的视觉反馈获得成就感和持续行动的动力。

第一版面向电脑浏览器。未来可能独立开发手机 App，后续技术设计应考虑复用账号和云端任务数据。

## 2. 使用范围

- 仅供本人使用，固定个人账号和密码登录，不开放注册。
- 数据保存在云端，同一账号换电脑登录后可以查看、继续编辑。
- 第一版以月历回顾记录，不提供额外统计面板。
- 不包含手机 App、专门的手机端适配、实物奖励或奖励领取功能。
- 不包含多人协作、公开分享、自动顺延、积分、排行榜或连续打卡机制。

## 3. 页面与布局

### 3.1 月历

- 登录后默认打开本月，并选中今天。
- 支持切换月份和“回到今天”。
- 每个日期直接展示任务名称和完成状态。
- 每格最多展示三条任务；长名称省略显示，完整名称可以在详情面板查看。
- 超过三条时显示“还有 N 项”，N 为未在格子中展示的任务数量，与完成状态无关。
- 日期格子保持整齐，不随任务数量无限增高。
- 当天已完成任务达到三个时，显示达成标记。

### 3.2 右侧详情面板

- 点击日期，在右侧展示该日期的全部任务和编辑入口，月历仍然可见。
- 可以直接点击其他日期，切换面板内容。
- 面板可查看完整任务名称、完成状态和可选备注。
- 支持新增、修改、删除任务、勾选完成、取消完成，以及移动未完成任务。

## 4. 任务与记录规则

### 4.1 任务内容

每条任务包含：所属日期、任务名称、完成状态、可选备注。任务名称为必填内容，备注不填也能正常使用。

### 4.2 两种记录方式

1. 先计划：在某个日期新增待完成任务，完成后勾选。
2. 做完再记：在所选日期直接新增已完成任务，无需先作为待办保存。

可以编辑过去、今天和未来的日期。过去的记录允许补记和修改，未来可以提前安排任务。

任务按所选日期归档，而不是按实际录入日期归档。例如今天补记昨天的跑步，应记录在昨天并计入昨天的完成数量。

### 4.3 每日目标

- 每日目标固定为完成三个任务，第一版不提供目标数量设置。
- 任务总数不限，额外任务也可继续记录。
- 达成条件：该日期当前已完成任务数量大于或等于三。
- 达成标记由当前记录计算，不是永久保留的历史徽章。
- 补记已完成任务同样计入目标。
- 取消完成或删除已完成任务后，重新计算；不足三个则移除达成标记。
- 备注和待完成任务不影响达成数量。

### 4.4 未完成任务与移动

- 未完成任务默认留在原日期，不自动顺延。
- 用户可以手动把未完成任务移动到另一个日期。
- 移动表示修改任务所属日期，原日期不再展示该任务，目标日期展示同一任务；不是复制。
- 移动保留名称、备注和未完成状态。

## 5. 保存与反馈

- 编辑后自动保存，无需手动点击保存按钮。
- 提供保存中、已保存、保存失败的可识别状态。
- 保存失败时保留用户输入，并支持重试，不把失败状态显示为已保存。
- 切换日期时，未保存成功的内容也应保留，避免编辑丢失。
- 保存成功的记录重新打开页面或换电脑登录后应保持一致。

## 6. 视觉与交互方向

- 整体风格温暖治愈，以暖白底色和柔和色彩为主。
- 完成任务时提供轻微动效。
- 达成每日目标后，日历显示明确的达成标记，并有适度庆祝感。
- 已完成与未完成任务应容易区分。
- 历史记录补记后同样获得达成标记，不使用特殊的补记惩罚或区别标记。

## 7. 关键验收场景

| 场景 | 预期结果 |
|---|---|
| 登录并首次进入 | 显示本月，选中今天，可在右侧编辑今天的任务 |
| 提前安排任务 | 在未来日期新增任务，保存后该日期展示待完成任务 |
| 完成每日第三条任务 | 该日期出现达成标记 |
| 添加第四条或更多任务 | 正常保存；月历最多显示三条，其余计入“还有 N 项” |
| 查看长任务名称 | 月历中省略，右侧面板可以查看和修改完整内容 |
| 补记昨天已完成的任务 | 记录归属昨天，计入昨天的完成数量 |
| 当天恰好完成三条后取消一条 | 已完成数量变为二，达成标记消失 |
| 当天恰好完成三条后删除一条已完成任务 | 已完成数量变为二，达成标记消失 |
| 手动移动未完成任务 | 原日期移除该任务，目标日期出现该任务，名称和备注保留 |
| 编辑任务或备注 | 自动保存，并反馈保存状态 |
| 保存失败 | 输入保留，明确显示失败，支持重试 |
| 换电脑登录 | 可以读取已经成功保存的任务及完成状态 |
| 浏览其他月份后点击“回到今天” | 返回本月并选中今天 |

## 8. 后续设计边界

本文件定义产品需求，不指定技术栈、数据库、云服务或部署方式。固定账号的初始化、密码管理、日期时区处理、保存冲突处理以及具体视觉稿，应在后续技术和界面设计中明确。当前不启动编码或部署。
