## 设计

- 沿用 Kratos、proto、Wire、GORM、MySQL 及统一错误封装。保留模板源代码，但不注册用户示例 HTTP/gRPC 路由。
- 固定账号在 dw_accounts 中离线初始化；bcrypt 哈希（使用 Go 官方 x/crypto，唯一新增运行时依赖）。JWT 增加随机会话标识；数据库会话支持撤销。默认七天绝对有效期，不滑动续期。
- 浏览器凭证仅在 HttpOnly、SameSite=Lax Cookie；生产启用 Secure。App 登录显式选择 bearer，凭证由 App 安全存储。所有 POST 要求自定义请求头，跨域仅允许明确来源。
- 业务日期保存 YYYY-MM-DD 字符串，时间戳单独保存。每天完成数量与达成状态实时计算。
- 任务 UUID + version 乐观锁；每次修改带 request_id，数据库事务内保存幂等结果。删除为 tombstone，恢复保留原 ID；已完成任务不能移动。
- 前端串行保存队列、失败保留原请求重试、409 不自动覆盖；按日期范围加载并保留内存草稿。旧 localStorage 保留、告知、可下载备份，无自动导入。

## 重点边界

1. 请求已提交但响应丢失，重试不能新增第二条记录。
2. 编辑请求在飞行中继续输入，旧响应不能覆盖新输入。
3. 退出/会话过期时仍有草稿，必须保留并阻止误报保存成功。
4. 跨月查询失败，不能把空白日历当作已加载的空数据。
5. 删除后撤销、移动后回看、取消第三条完成，都按当前数据计算达成。
